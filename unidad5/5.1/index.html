¿Qué es el Punto de Equilibrio (PE)?

El Punto de Equilibrio (Break-Even Point, BEP) es el nivel de producción o ventas donde los ingresos totales son exactamente iguales a los costos totales. En ese punto, la utilidad es cero: no hay ganancia ni pérdida.

En seguridad industrial: El PE permite determinar cuántas inspecciones, auditorías, servicios de monitoreo o productos de seguridad deben fabricarse/prestarse para que la unidad de seguridad industrial sea financieramente autosostenible sin generar pérdidas.

Componentes Fundamentales

Costos Fijos (CF)

No varían con el volumen: salarios base, alquileres, seguros, depreciación, licencias de software. Se pagan se produzca o no.

Costos Variables (CV)

Varían directamente con el volumen: materiales directos, horas extras, insumos consumidos por servicio, viáticos de inspectores.

Precio de Venta (PV)

Ingreso por unidad. En seguridad: tarifa por inspección, precio por casco, costo por hora de consultoría.

Modelo Básico

Punto de Equilibrio de Una Línea

El caso más simple: un solo producto o servicio con costos fijos constantes, costo variable unitario constante y precio de venta constante en todo el rango de producción.

Ingreso Total
$$IT = PV \times Q$$

\(PV\) = precio de venta unitario, \(Q\) = cantidad producida/vendida.

Costo Total
$$CT = CF + CV_u \times Q$$

\(CF\) = costos fijos totales, \(CV_u\) = costo variable unitario.

Condición de Equilibrio
$$IT = CT \implies PV \times Q^* = CF + CV_u \times Q^*$$

Fórmulas del Punto de Equilibrio

PE en Unidades
$$Q^* = \frac{CF}{PV - CV_u} = \frac{CF}{MC_u}$$

\(MC_u = PV - CV_u\) = margen de contribución unitario. Debe ser \(> 0\).

PE en Valores ($)
$$PE_{\$} = PV \times Q^* = \frac{CF}{\dfrac{MC_u}{PV}} = \frac{CF}{\%MC}$$

\(\%MC = \frac{MC_u}{PV}\) = razón de margen de contribución.

Margen de Contribución

Margen de Contribución Unitario
$$MC_u = PV - CV_u$$
Margen de Contribución Total
$$MC_T = MC_u \times Q = IT - CV_T$$

Interpretación: El margen de contribución es lo que cada unidad vendida "aporta" para cubrir los costos fijos y luego generar utilidad.

Ejemplo: Servicio de Inspecciones Técnicas de Seguridad

Caso Aplicado

Una empresa de seguridad industrial ofrece inspección técnica de equipos a presión.

Precio por inspección (PV): $850

Costo variable por inspección (CV_u): $320 (inspector $180, materiales $50, transporte $60, seguros $30)

Costos fijos mensuales (CF): $42,000 (salarios administrativos $22,000, alquiler $8,000, depreciación $5,000, seguros $3,000, servicios $4,000)

Cálculo
$$MC_u = 850 - 320 = \$530 \qquad Q^* = \frac{42{,}000}{530} = 79.25 \approx 80 \text{ inspecciones/mes}$$ $$PE_{\$} = 850 \times 79.25 = \$67{,}363 \qquad \%MC = \frac{530}{850} = 0.6235 = 62.35\%$$

Interpretación: Se necesitan al menos 80 inspecciones mensuales ($67,363 en facturación). Cada inspección adicional genera $530 de utilidad.

Variante: Tramos

Punto de Equilibrio por Tramos

Cuando los costos fijos o variables cambian al superar ciertos niveles de producción.

En seguridad industrial: Al superar cierto volumen de inspecciones, se requiere contratar un segundo equipo, incrementando los costos fijos y generando un segundo tramo.

Metodología

  • Identificar los tramos y los puntos de cambio (\(Q_c\))
  • Definir CF, CV_u y PV para cada tramo
  • Calcular el PE de cada tramo
  • Verificar que el PE cae dentro del rango válido del tramo
  • Seleccionar el PE válido
    • PE del Tramo j
    $$Q^*_j = \frac{CF_j}{PV_j - CV_{u_j}}$$

    Condición de validez: \(Q^*_{j-1} \leq Q^*_j < Q_{c_j}\). Si no se cumple, el PE no existe en ese tramo.

    Ejemplo: Servicio de Monitoreo de Atmosferas

    Tramo 1 (Q < 120 servicios/mes): CF₁ = $28,000, CV_u₁ = $180, PV = $450

    Tramo 2 (Q ≥ 120 servicios/mes): CF₂ = $45,000, CV_u₂ = $165, PV = $450

    Cálculo por Tramos
    $$Tramo\ 1:\ Q^*_1 = \frac{28{,}000}{450 - 180} = \frac{28{,}000}{270} = 103.7 \text{ servicios} \quad \checkmark\ (103.7 < 120)$$ $$Tramo\ 2:\ Q^*_2 = \frac{45{,}000}{450 - 165} = \frac{45{,}000}{285} = 157.9 \text{ servicios} \quad \text{(157.9 < 120 ✗ NO VÁLIDO)}$$

    Resultado: Solo el Tramo 1 tiene PE válido (104 servicios). El Tramo 2 arroja un PE de 158 que no cae en su rango (debe ser ≥120). Esto significa que la expansión no tiene un segundo punto de equilibrio propio; el único PE factible es 104 servicios con un equipo.

    Variante: Semifijos

    PE con Costos Semifijos (Mixtos)

    Costos que tienen un componente fijo y uno variable simultáneamente.

    Ejemplo: Energía eléctrica con tarifa fija mínima más cargo variable por kWh. Salarios con sueldo base más horas extras proporcionales al volumen.

    Estructura de Costo Semifijo
    $$CS_i(Q) = CF_{base_i} + CV_{adicional_i} \times Q$$
    Costo Total con Costos Semifijos
    $$CT = \underbrace{\sum_{i \in Fijos} CF_i}_{CF_{puros}} + \underbrace{\sum_{j \in Variables} CV_{u_j} \times Q}_{CV_{puros}} + \underbrace{\sum_{k \in Semifijos} (CF_{base_k} + CV_{ad_k} \times Q)}_{CS}$$
    PE con Costos Semifijos
    $$CT = CF_{total} + CV_{total\_u} \times Q^* \implies Q^* = \frac{CF_{total}}{PV - CV_{total\_u}}$$

    \(CF_{total} = \sum CF_{puros} + \sum CF_{base\_semifijos}\) y \(CV_{total\_u} = \sum CV_{u\_variables} + \sum CV_{ad\_semifijos}\).

    Ejemplo: Planta de Recarga de Extintores

    PV por recarga: $45 | CV variables puros: $12 | CF puros: $8,500

    Energía (semifijo): Base $600 + $0.80/recarga | Salarios (semifijo): Base $4,200 + $1.50/recarga

    Agrupación
    $$CF_{total} = 8{,}500 + 600 + 4{,}200 = \$13{,}300 \qquad CV_{total\_u} = 12 + 0.80 + 1.50 = \$14.30$$ $$Q^* = \frac{13{,}300}{45 - 14.30} = \frac{13{,}300}{30.70} = 433.2 \approx 434 \text{ recargas/mes}$$
    Multiproducto

    PE Multiproducto con Restricción de Capacidad

    Múltiples productos o servicios con diferentes márgenes y una restricción de capacidad.

    Método: PE por Producto Individual con Restricción

    PE del Producto i
    $$Q^*_i = \frac{CF_{asignados_i}}{MC_{u_i}} = \frac{CF_{asignados_i}}{PV_i - CV_{u_i}}$$
    Asignación de Costos Fijos Compartidos
    $$CF_{asignados_i} = CF_{directos_i} + CF_{comunes} \times w_i \qquad \sum w_i = 1$$
    Verificación de Capacidad
    $$\sum_{i=1}^{n} t_i \times Q^*_i \leq T_{disponible}$$
    Índice de Prioridad (recurso restrictivo)
    $$IP_i = \frac{MC_{u_i}}{t_i} \quad \text{(margen por unidad de recurso consumido)}$$

    Nota: Factor de Contribución Promedio Ponderado. Existe un método alternativo: \(MC_u^{prom} = \frac{\sum MC_{u_i} \times Q_i}{\sum Q_i}\). Se deja planteado para análisis posterior en el tema 5.2, donde se compararán sus limitaciones frente al método individual con restricción.

    Análisis de Sensibilidad del Punto de Equilibrio

    Determinar cómo se desplaza el PE cuando las variables cambian individualmente, y evaluar escenarios aplicados a un caso real de seguridad industrial.

    Efecto de Cada Variable sobre el PE

    Sensibilidad del PE ante cambios porcentuales
    $$\frac{\partial Q^*}{\partial CF} = \frac{1}{MC_u} > 0 \quad (CF \uparrow \rightarrow PE \uparrow) \qquad \frac{\partial Q^*}{\partial PV} = \frac{-CF}{(PV - CV_u)^2} < 0 \quad (PV \uparrow \rightarrow PE \downarrow)$$ $$\frac{\partial Q^*}{\partial CV_u} = \frac{CF}{(PV - CV_u)^2} > 0 \quad (CV_u \uparrow \rightarrow PE \uparrow)$$

    Conclusión: El PE es más sensible al precio de venta y al costo variable (afectan al denominador al cuadrado) que a los costos fijos (numerador lineal).
