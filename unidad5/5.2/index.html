¿Qué se logra en este tema?

El Tema 5.1 te enseñó a calcular el punto de equilibrio. Ahora el 5.2 te enseña a interpretar ese resultado: ¿la empresa gana o pierde? ¿Cuánto? ¿Es viable invertir? ¿Qué opción es mejor? Pasamos del cálculo mecánico a la toma de decisiones financieras aplicadas a seguridad industrial.

Enfoque de Seguridad Industrial: Todos los ejemplos, ejercicios y la tarea aplicada usan datos del sector: servicios de inspección, monitoreo, auditorías SGSST, fabricación de EPP, consultoría en higiene industrial.

Fundamento

Estados de Pérdida y Ganancia

A partir del punto de equilibrio, determinar si la operación genera utilidad o pérdida según el volumen real de producción o servicios.

Ingreso Total
$$IT = PV \times Q$$
Costo Total
$$CT = CF + CV_u \times Q$$
Utilidad (o Pérdida)
$$U = IT - CT = (PV - CV_u) \times Q - CF = MC_u \times Q - CF$$

Los Tres Estados Posibles

Pérdida

\(Q < Q^*\) → \(IT < CT\) → \(U < 0\). La empresa no cubre sus costos. Zona roja del gráfico.

Punto de Equilibrio

\(Q = Q^*\) → \(IT = CT\) → \(U = 0\). Umbral exacto. Ni gana ni pierde.

Ganancia

\(Q > Q^*\) → \(IT > CT\) → \(U > 0\). La empresa cubre costos y genera utilidad. Zona verde.

Ejemplo: Servicio de Monitoreo de Gases Tóxicos

Caso Aplicado

PV por monitoreo: $850 | CV_u: $340 | CF mensuales: $35,000

El mes pasado realizaron Q = 60 monitoreos.

Cálculo del Estado
$$MC_u = 850 - 340 = \$510 \qquad Q^* = \frac{35{,}000}{510} = 68.63 \text{ monitoreos}$$ $$IT = 850 \times 60 = \$51{,}000 \qquad CT = 35{,}000 + 340 \times 60 = \$55{,}400$$ $$U = 51{,}000 - 55{,}400 = \boxed{-\$4{,}400} \quad \textbf{PÉRDIDA}$$

Interpretación: Con 60 monitoreos (por debajo del PE de 69), la empresa pierde $4,400. Necesita al menos 9 monitoreos adicionales para salir de pérdidas. Cada monitoreo por encima del PE aporta $510 de utilidad neta.

Extensión

Análisis de Utilidad Objetivo mediante PE

Determinar cuántas unidades deben venderse no solo para cubrir costos, sino para alcanzar una meta de utilidad específica.

Condición de Utilidad Objetivo
$$U_{obj} = MC_u \times Q_{obj} - CF \implies Q_{obj} = \frac{CF + U_{obj}}{MC_u}$$
Relación con el PE
$$Q_{obj} = Q^* + \frac{U_{obj}}{MC_u}$$

El Q objetivo es el PE más las unidades adicionales necesarias para generar la utilidad deseada.

Ingresos en el Q Objetivo
$$IT_{obj} = PV \times Q_{obj} = PE_{\$} + \frac{U_{obj}}{\%MC}$$

Ejemplo: Consultoría en Higiene Industrial

CF = $28,000/mes | PV = $650/consultoría | CV_u = $250/consultoría | Meta de utilidad: $15,000/mes

Cálculo
$$MC_u = 650 - 250 = \$400 \qquad Q^* = \frac{28{,}000}{400} = 70 \text{ consultorías}$$ $$Q_{obj} = \frac{28{,}000 + 15{,}000}{400} = \frac{43{,}000}{400} = 107.5 \rightarrow 108 \text{ consultorías}$$ $$IT_{obj} = 650 \times 108 = \$70{,}200 \qquad CT_{obj} = 28{,}000 + 250 \times 108 = \$55{,}000$$ $$U = 70{,}200 - 55{,}000 = \$15{,}200 \geq \$15{,}000 \quad \checkmark$$

Interpretación: Se necesitan 108 consultorías (38 adicionales al PE de 70). El margen de seguridad respecto al PE es: \((108-70)/108 \times 100 = 35.2\%\).

Aplicación

Evaluación de Inversión mediante PE

Usar el punto de equilibrio como filtro de viabilidad: comparar el PE con la demanda esperada para decidir si una inversión es factible.

Criterio de Viabilidad

VIABLE

\(Q^* < Q_{demanda}\) → La demanda supera el PE. Existe margen de seguridad positivo. La inversión puede generar utilidad.

NO VIABLE

\(Q^* > Q_{demanda}\) → La demanda no alcanza el PE. La operación generaría pérdidas. No invertir sin cambios.

Índice de Viabilidad
$$IV = \frac{Q_{demanda} - Q^*}{Q^*} \times 100$$

Si \(IV > 0\): viable. Si \(IV \leq 0\): no viable. Es equivalente al MS% pero referido al PE inyectado a las ventas.

Ejemplo: Planta de Fabricación de EPP

Se evalúa instalar una línea de producción de cascos de seguridad. Demanda esperada: 85 cascos/mes.

CF de la inversión: $42,000/mes (depreciación, mantenimiento, personal fijo)

PV por casco: $780 | CV_u: $310

Evaluación
$$MC_u = 780 - 310 = \$470 \qquad Q^* = \frac{42{,}000}{470} = 89.36 \rightarrow 90 \text{ cascos}$$ $$IV = \frac{85 - 89.36}{89.36} \times 100 = -4.88\%$$

Conclusión: NO VIABLE. El PE (90 cascos) supera la demanda (85). Faltan 5 cascos para alcanzar el equilibrio. Opciones: (a) aumentar precio, (b) reducir costos, (c) no invertir.

Si se reduce CV_u a $270 (negociando proveedores): \(MC_u = 510\), \(Q^* = 42{,}000/510 = 82.4 \rightarrow 83\), \(IV = (85-82.4)/82.4 = 3.2\%\). Ahora es viable, aunque con muy poco margen.

Análisis Avanzado

Comparación de Opciones de Inversión

Cuando existen múltiples alternativas con diferentes estructuras de costos, el PE permite identificar cuál opción es mejor según el volumen esperado.

Metodología

  • Calcular el PE de cada opción
  • Encontrar el punto de indiferencia: volumen donde ambas opciones generan la misma utilidad
  • Comparar la utilidad de cada opción en el volumen esperado
    • Punto de Indiferencia (mismo PV)
    $$CT_A = CT_B \implies CF_A + CV_{u_A} \times Q_{ind} = CF_B + CV_{u_B} \times Q_{ind}$$ $$Q_{ind} = \frac{CF_B - CF_A}{CV_{u_A} - CV_{u_B}}$$

    Si \(CV_{u_A} < CV_{u_B}\) (A tiene menor costo variable), entonces para \(Q > Q_{ind}\) la opción A es siempre mejor.

    Punto de Indiferencia

    Ejemplo Numérico: Servicio de Inspección de Extintores

    Opción A (manual): CF=$30,000, CV_u=$220, PV=$600

    Opción B (semi-automatizada): CF=$48,000, CV_u=$160, PV=$600

    Demanda esperada: 200 inspecciones/mes

    Cálculo Comparativo
    $$PE_A = \frac{30{,}000}{380} = 78.9 \rightarrow 79 \qquad PE_B = \frac{48{,}000}{440} = 109.1 \rightarrow 110$$ $$Q_{ind} = \frac{48{,}000 - 30{,}000}{220 - 160} = \frac{18{,}000}{60} = 300 \text{ inspecciones}$$ $$U_A(200) = 380 \times 200 - 30{,}000 = \$46{,}000 \qquad U_B(200) = 440 \times 200 - 48{,}000 = \$40{,}000$$

    Resultado: Con demanda de 200 (por debajo del punto de indiferencia de 300), la Opción A gana por $6,000. Solo si la demanda supera 300 inspecciones, la Opción B sería mejor. La Opción A tiene menor PE (79 vs 110) y es la elección correcta.

    Integración

    Modelo de Decisión con Punto de Equilibrio

    Flujo de 5 pasos para tomar decisiones de inversión en seguridad industrial utilizando el análisis del PE y sus indicadores derivados.

    Paso 1 — Recopilar Datos

    Obtener CF, CV_u, PV y demanda esperada (\(Q_d\)) del proyecto o servicio de SI.

    Paso 2 — Calcular PE y Evaluar Viabilidad

    Calcular \(Q^*\) y comparar con \(Q_d\). Si \(Q^* > Q_d\) → NO VIABLE, ir al Paso 4. Si \(Q^* < Q_d\) → VIABLE, continuar.

    Paso 3 — Analizar Margen y Riesgo

    Calcular \(MS_{\%}\) e \(IV\). Si \(MS_{\%} < 20\%\) → riesgo alto, requiere monitoreo estrecho. Calcular \(Q_{obj}\) si hay meta de utilidad.

    Paso 4 — Evaluar Alternativas (si no es viable)

    Proponer: (a) aumentar PV, (b) reducir CV_u, (c) reducir CF, (d) aumentar demanda. Recalcular PE con cada alternativa.

    Paso 5 — Comparar y Decidir

    Si hay múltiples opciones, calcular \(Q_{ind}\) y utilidad en \(Q_d\) para cada una. Seleccionar la de mayor utilidad o menor riesgo según el contexto.

    Caso Integrado: Servicio de Señalización Industrial

    Una empresa de SI evalúa lanzar un servicio de señalización de zonas de riesgo.

    Datos: CF=$32,000/mes, PV=$480/señalización, CV_u=$200, Demanda esperada=90 und/mes

    Aplicación del Modelo
    $$MC_u = 280,\quad Q^* = \frac{32{,}000}{280} = 114.3 \rightarrow 115 > 90 \quad \textbf{NO VIABLE}$$ $$\text{Paso 4a (subir PV a \$520): } Q^* = \frac{32{,}000}{320} = 100 \quad \text{aún } > 90 \text{ NO}$$ $$\text{Paso 4b (reducir CV_u a \$170): } Q^* = \frac{32{,}000}{310} = 103.2 \rightarrow 104 \quad \text{aún } > 90 \text{ NO}$$ $$\text{Paso 4c (reducir CF a \$24{,}000): } Q^* = \frac{24{,}000}{280} = 85.7 \rightarrow 86 < 90 \quad \textbf{VIABLE}$$ $$\text{Paso 3: } MS_{\%} = \frac{90-86}{90} \times 100 = 4.4\% \quad \text{Riesgo MUY ALTO}$$ $$\text{Paso 4c+4b combinado: CF=24{,}000, CV_u=170 \rightarrow Q^* = \frac{24{,}000}{310} = 77.4 \rightarrow 78$$ $$MS_{\%} = \frac{90-78}{90} \times 100 = 13.3\% \quad U = 310 \times 90 - 24{,}000 = \$3{,}900$$

    Decisión: Solo la combinación de reducir CF (subcontratar parte de la operación) Y negociar costos variables hace el proyecto viable, pero con MS%=13.3% (riesgo alto). Se recomienda condicionar el lanzamiento a contratos firmes que garanticen al menos 100 unidades/mes.
